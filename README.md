# Marketing Campaign Performance Analytics

## 📌 Project Overview

Marketing Campaign Performance Analytics is an end-to-end data analytics project that analyzes marketing campaign performance across different channels and campaigns.

The project uses **Excel, SQL, Python, and Power BI** to clean, analyze, visualize, and generate insights from marketing data.

---

## 🎯 Objectives

* Analyze marketing campaign performance.
* Compare different marketing channels.
* Analyze revenue, spend, and conversions.
* Calculate and analyze ROI and ROAS.
* Analyze monthly marketing performance.
* Identify high-performing campaigns and channels.
* Build an interactive Power BI dashboard.

## 📐 Key Metrics

### ROI

```text
ROI = (Revenue - Spend) / Spend × 100
```

### ROAS

```text
ROAS = Revenue / Spend
```

### CTR

```text
CTR = Clicks / Impressions × 100
```

### Conversion Rate

```text
Conversion Rate = Conversions / Clicks × 100
```

### CPC

```text
CPC = Spend / Clicks
```

### CPA

```text
CPA = Spend / Conversions
```
